# Slitline

陸上競技の記録計測で用いられる**写真判定（スリットスキャン）システム**を模したデスクトップアプリケーションです。
動画ファイルを読み込むだけで、個人でも簡単な操作でゴールタイムの判定用画像を作成・確認できます。  
※あくまでデスクトップアプリケーション開発の学習を目的としてテスト開発であるため、アプリケーションを実行する際は開発環境での実行になります。

## 特徴

- 動画（`.mov` / `.mp4`）から自動でスリットスキャン画像（フィルムストリップ）を生成
- フィルムストリップをズーム・スクロールしながらフレーム単位で確認可能
- 任意の位置を「スタート地点」として基準に設定し、そこからの経過時間をリアルタイム表示
- フレーム境界を示す目盛り線・現在位置を示す中心線で、着差判定をサポート

## 使い方

### 1. 記録判定用の動画の撮影
iPhone、Androidスマートフォンでスローモーション映像の状態でゴールラインを中心に設定し、レースを撮影する。  
この際、スローモーション映像の設定にて120FPSあるいは240FPSの設定を行うことでより高い精度で測定が可能となる。  
その他、高フレームレートの撮影が可能なカメラを使用した撮影なども可

### 2. アプリの起動

```powershell
python main.py
```

### 3. 動画の読み込み・スリットスキャン画像の生成

1. 「ファイルを選択」ボタンから判定したい動画ファイル（`.mov` / `.mp4`）を選ぶ
2. 「画像処理開始」ボタンを押すと、動画からスリットスキャン画像（フィルムストリップ）が生成され、判定画面に切り替わる

### 4. 判定画面での操作

| 操作 | 内容 |
| --- | --- |
| マウスホイール | 横スクロール |
| `Ctrl` + マウスホイール | カーソル位置を中心にズームイン・アウト |
| `←` / `→` | 1フレーム分左右に移動 |
| `Shift` + `←` / `→` | 10フレーム分左右に移動 |

- 画面中央の黒い縦線が現在の判定位置（カーソル）です。フィルムストリップ上には、フレームごとの目盛り線（10フレームごとに太い線）が表示されます。
- スタート合図の位置に中心線を合わせ、「この位置をスタートに設定」ボタンを押すと、その位置が0秒地点になります。
- 以降、中心線が指すフレームの経過時間が画面上部に「経過時間: X.XXX秒（フレーム N）」の形式でリアルタイム表示されます。

## プロジェクト構成

```
slitline/
├── main.py            # アプリのエントリーポイント（画面遷移・全体のUI構築）
├── create_images.py   # 動画からスリットスキャン画像を生成する処理
├── edit.py             # 判定画面（フィルムストリップの表示・スクロール・時間計算）
└── requirements.txt    # 依存パッケージ一覧
```
